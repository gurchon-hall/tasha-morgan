# Engine mechanisms (ENG)

An engine mechanism a card needs (a hook, a subsystem), a gap in
one, or an engine bug found in review. While an entry is `open`,
the cards it impacts are blocked with `blocked_reason="ENG-<nnn>"`.

One file per entry: `ENG-<nnn>-<slug>.md`, numbered from 001,
never reused or renumbered. Front matter: `status` (`open` / `resolved`
/ `superseded` + `superseded_by`), `date`, `cards` (semicolon-separated).
Body: Open: `Situation` / `Sources read` / `Needed mechanism` /
`Impacted code`. Resolved: exactly `Situation` /
`Rules & interactions` / `Solution`.
