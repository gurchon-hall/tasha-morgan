# Open questions archive index

`docs/OPEN_QUESTIONS.md` is capped at 25 entries (see
`docs/DECISIONS.md` D-6). When it overflows, the oldest `resolved`
entries move here, verbatim, into `<NNN>.md` files of at most 25
entries each. This index maps every archived `OQ-<n>` to the file
that holds it. Update it in the same change that moves an entry.
