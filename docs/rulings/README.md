# Rulings (RUL)

How a rule or a card text is read when the official sources do not
settle it (CLAUDE.md §2). While an entry is `open`, the code path
raises `UnresolvedRulingError("RUL-<nnn>")` or the card is blocked,
until the user rules.

One file per entry: `RUL-<nnn>-<slug>.md`, numbered from 001,
never reused or renumbered. Front matter: `status` (`open` / `resolved`
/ `superseded` + `superseded_by`), `date`, `cards` (semicolon-separated).
Body: Open: `Situation` / `Sources read` / `Candidate readings` /
`Impacted code`. Resolved: exactly `Situation` /
`Rules & interactions` / `Solution`.

Generated by `scripts/docs_index.py` -- do not edit by hand.
